# ハード確認の再発防止

- 設計資料を開く前に実在ファイルを列挙する。旧v86 STEPを指定しない。現チェックアウトのv3と現在実機の一致は別に確認する。
- STEPの外形寸法はトポロジーVERTEX_POINTを用い、面原点・曲線制御点を全点群として寸法へ混ぜない。軸中心はCIRCLE配置中心の同軸性と既知寸法で照合する。
- KiCadはValueだけで部品を探さずReference・library ID・footprint回転も確認する。基板→機体座標変換、単位、出典SHA256を保存する。フィットしたyIや経験的トレッドを物理寸法へ転記しない。
- BMI088はBMI088.c/.h、IMU.c/.h、main.c、iocを一緒に確認する。SPI2はAPB1=45 MHz/8=5.625 MHz。リセット後30ms以上、加速度単一レジスタのダミー、ACC_PWR_CONF/CTRL、通信成否・ID・設定読戻しを確認する。GYRO_BANDWIDTHの読出専用bitを設定不一致としない。
- 設定意図と実レジスタを分けて報告する。校正読出しエラー0や走行完了だけでODR/帯域・通信仕様適合を証明しない。
- 生Yはユーザー確認済みの前方正。X/ZはY確認から推定しない。生軸→符号変換→校正→向心/接線位置補正→利用側を順に照合する。旧Yログには位置補正も含まれるため列全体を単純反転しない。
- 正負加速度、CW/CCWの定常旋回・正負角加速度の合成入力で軸と位置補正を検証する。LPFを通す実装では残留誤差を式から確認する。実配線/生軸の確認を合成テストで代替しない。
- ADC/LED位相変更はioc・回路・main/タイマー・DMA・割込み優先度・取得→平均→公開の全経路を確認する。単発欠測後の復帰だけでなく、4スロット各位置の周期欠測を100周期以上継続し、公開回数の下限・期限切れ・電源世代・OFF/ON・重複ON要求を検証する。
- UIがONを毎ループ要求する場合、重複要求で取得/平均化を消さない。取得成功と公開継続は別指標。無欠測の変更前raw/正規化/PID回帰も維持する。静止・走行分岐外の成功だけで実走行の更新を保証しない。
