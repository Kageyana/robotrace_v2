# ログ解析の再発防止

対象CSVを数値計算へ渡す前に以下を確認する。原本を変更せず、除外番号・理由・入力SHA256を成果物へ残す。

## 入力境界

- CSVは拡張子だけで選ばない。basenameがASCIIの `^[0-9]+$` に一致するものだけを整数化し、数値の範囲・件数・欠落番号を照合する。`imu_temp_*.csv`、boost、bin/part/tmpは別形式。
- 既存の `analysis/script/check_additional_logs_13238_13247.py` の `discover()` を参照する。新しい処理へ流用するときも呼出契約を読む。
- メタデータ・ヘッダ・全データ行の列数を検査する。末尾空セルは仕様として別に数え、欠損列名とは区別する。固定長読込なら物理行末まで読む。派生列も含む実CSVの列数を使う。
- 整数相当メタデータはfloatへ変換後、有限・整数相当・範囲を検証してint化する。`2`/`2.00`は受理、`2.5`/`nan`/`inf`は拒否し、端数を切り捨てない。
- 短い行・非数値・NUL・改行不整合は番号と理由を記録する。全件分類では個別例外で全体を止めずABNORMALへ分ける。NUL除去は読込コピー内に限り、破損フラグを残す。有限値なしでnanmaxや平均を呼ばない。
- CSVイテレータはファイルのwith内で消費する。描画へ渡すCSV数値列は文字列のままにしない。新規標準ライブラリ参照はimport一覧と実行の両方で確認する。

## 時刻・距離・単位

- U16 cntlogの65535→0の既知折返しは、対応形式と連続性を確認して解析側だけ65536 msを加算する。任意の逆行を折返しとして救済しない。時間重みを作る前に正差分を確認する。ユーザー方針により、この対策のためファームの時刻形式は変更しない。
- 距離基準ログに固定の11ms上限や特定速度の3～7mm範囲を流用しない。logDistanceTargetMm、速度、1ms量子化、残余持越し、期待行数、raw左右積算平均の距離差を合わせて欠落を調べる。大きな時刻間隔だけで処理落ちと断定しない。
- load境界でraw積算と補正座標を区別する。DISTANCE/SLIPのencTotalOptimal後退は、マーカー遷移と当該コード・設定の補正上限を照合する。後退を一律拒否も無条件許可もしない。物理進捗の健全性はraw左右平均を優先する。
- XY再計算には符号付き補正距離差と保存済みimuAngle_Zの両端平均を用い、負差分を0へ丸めない。疎なgyro再積分は旧形式の近似として明示する。
- mm/msの数値はそのままm/s。encCurrent[pulse/ms] / PULSE_MILLIMETERでm/s、加速度gにはGRAVITY_MPS2を掛ける。速度の既知範囲と距離/時間の独立計算で換算を確認する。

## 完走・比較条件

- 連番やemcStop=0だけで完走としない。モード、終了メタデータ、期待行数、経路終端または当時のゴール条件を確認する。右マーカー数はSG加算数ではない。PATH系は経路弧長終端を使い、旧ログへ現在のSG回数を押し付けない。
- autoStartは系列・一次参照・run番号1～5と全走の完走を確認する。1本でも欠落・失敗・未完了ならセット全体を採用比較から除外し、診断用として残す。
- 性能の計算前に、方式、要求方式、run番号、一次/SLIP参照、速度表全体、加減速/lead、PID、FF、電圧、校正、スキーマ、ビルドを比較表へ出す。同一gitCommitでもSD設定は違う。終了ヘッダのPIDはchangeGain()による動的切替値の場合がある。
- 通常性能と低電圧ストレス・手持ち/空転を分ける。平均・最小電圧と比較適格理由を出し、過去の電圧しきい値を固定ルールへ戻さない。
- PWM/電圧飽和とlapの相関を因果や改善と呼ばない。速度追従、スリップ、完走、出力余裕を同じ条件内で評価する。

## イベント・推定・集計

- CROSS存在と姿勢フィット品質は別に検証する。品質不足イベントだけ理由付きで除外し、有効通過数と実際の比較周回数を出す。飛ばしたイベント間を1周と数えない。
- CROSS確定には検出位置と幅確認の遅延がある。IMU位置同定では独立ラインイベント・素子位置・アンカー±20mm感度・積分則感度を確認する。最適値の安定だけで物理レバーアームを採用しない。
- Yaw融合では学習/留保を固定し、ソルバー終了理由・制約到達・数値検算・物理妥当性を分けて出す。gyro地図や設計DXFへの距離を真のYaw精度と呼ばない。平均地図/各一次地図/独立形状で参照依存性を確認し、評価結果で係数を選び直さない。
- 解析ユーティリティは必要キーと前処理を読む。既存Yaw解析の依存順はwindows→attach→observation_masks。
- 直線形状・指令加減速・観測Yawは別ラベル。ぶれの解析で実gyroの小ささを直線選別に使わない。
- 空の方式/区間は集計行を作らず標本数を残す。主表だけでなくログ別・感度表・全図入力も有限値検査し、JSONはallow_nan=Falseで保存する。欠測を0や正常値へ置換しない。
- 曲線は同一系列内のxを昇順・重複なしにしてから結ぶ。数値誤差上限は離散式・保存型から導き、assert失敗に合わせて恣意的に緩めない。全グラフを保存後に確認する。
