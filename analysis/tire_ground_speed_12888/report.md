# 指定した旋回中心から各タイヤの移動速度を推定

## 仮定と角度

機体中心を前後車軸・左右タイヤ中心間の中点とし、その横方向に曲率半径Rだけ離れた点を旋回中心とする。旋回中心の前後位置は機体中心と同じ。CAD解析済みの前後軸間隔L=25.690465 mm、左右タイヤ中心間隔B=109.1 mmを使用する。接触面の有効中心位置・荷重による変化は未測定。

旋回中心から各側の前後輪中点までの距離成分をqとすると、外輪q=R+B/2、内輪q=R-B/2。タイヤまでの半径rとユーザー指定の角度βは次のとおり。

```
a = L/2 = 12.845233 mm
r = sqrt(q² + a²)
β = atan2(a, abs(q))
cosβ = abs(q)/r
```

このβは、旋回中心からタイヤへの半径と、旋回中心から前後輪中点への半径とのなす鋭角である。移動速度は半径に直角なので、車輪の前進方向と移動方向との鋭角も同じβとなる。前後輪の横方向成分は反対向きで、この仮定では速度の大きさは等しい。内輪q<0では前進方向成分が逆転するため、鋭角βだけでは方向を表せず符号を別に保持する。

## 2通りの速度計算

縦滑りがない場合、エンコーダの車輪方向速度v_encと移動速度の大きさVには次の関係がある。

```
V_encoder = abs(v_enc) / cosβ
```

これはエンコーダを斜め速度の大きさとして扱ってcosを掛ける計算とは異なる。角度を指定することで未観測の横成分を仮定し、既に測定した前進成分から斜め速度を推定している。このVに再度cosを掛けると元のエンコーダ値に戻る。

同じ旋回中心を持つ剛体の運動なら、IMUからも計算できる。

```
V_gyro = abs(ω) × r
v_forward_expected = ω × q   （CW、前進の例）
abs(v_lateral_expected) = abs(ω) × a
```

ωはrad/s、rをmにすれば速度はm/s。両式が一致するにはエンコーダの前進成分がωqと一致する必要がある。任意のR、寸法、IMU角速度、左右エンコーダを独立に代入すると必ず一致するわけではない。

## 12888の第二コーナー

6周の角速度100 deg/s超が続く区間のうち、10行以上かつ平均300 deg/s前後の6区間を抽出。実装上の平均角速度条件は250 deg/s超。瞬間入力は現行calcROCと同じencCurrentN、gyroVal_Zを使用し、R=v_center/ωとする。直線用の3000 mmへの置換は選択したコーナー内では行わない。速度の平均は各CSV行の単純平均であり、積算距離÷所要時間とは異なる。

1周目は1.910～2.484 s、61行。

|タイヤ|βの中央値|エンコーダ平均 [m/s]|エンコーダ/cosβの平均 [m/s]|IMU角速度×半径の平均 [m/s]|
|---|---:|---:|---:|---:|
|左前・左後（外輪）|4.60°|0.7988|0.8014|0.7892|
|右前・右後（内輪）|14.29°|0.2498|0.2591|0.2759|

前後でβの大きさは同じだが、横移動の向きが逆。平均速度を角度中央値のcosで割ったのではなく、各行で計算後に平均した。

2.321 sの内輪停止サンプルでは、機体中心半径R=66.342 mm、内輪半径r=17.437 mm、β=47.449°。外輪エンコーダ0.98244 m/s、内輪0 m/s。

|タイヤ|エンコーダ/cosβ [m/s]|IMU角速度×半径 [m/s]|
|---|---:|---:|
|左前・左後（外輪）|0.98797|0.88437|
|右前・右後（内輪）|0|0.12684|

仮定した旋回中心なら内輪の前進成分も0.08578 m/sとなるはずだが、エンコーダは0。したがってこのサンプルで両方を同時に真値として扱うことはできない。瞬間値の振動・記録時点の差、縦滑り、旋回中心位置の違い、寸法やセンサー誤差のどれが支配的かは未確定。内輪が停止したことだけで特定の原因とは断定しない。

旋回中心が前後輪中点と一致するq=0ではβ=90°でcosβ=0となるため、エンコーダから横移動速度は求められない。スクリプトはcosβ<0.05を逆算不能として空欄にする。この6コーナー内では該当行は0だった。
