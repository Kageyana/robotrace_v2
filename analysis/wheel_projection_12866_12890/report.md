# IMU旋回角度による車輪速度成分の再計算

画像のベクトルを再構成して前進成分を求める計算では、元の左右エンコーダ平均と同一になり、プロットは変化しなかった。エンコーダ値にさらにcosを掛ける仮説計算も実施したが、X＋方向の周回ずれはほぼ残り、動画対象12888では閉路誤差が悪化した。現時点でファームウェアへの採用根拠はない。

## 対象と検証方法

- CW12866～12868、CCW12869～12871、CW12885～12888・12890の正常終了11ログ。方向は積算IMU角度の符号でも確認。
- 12889はemcStop=3、閉路無効、距離換算検証未完了のため除外。
- 正常終了、期待行数一致、時刻単調増加・最大間隔11 ms以下、必要列の有限値、IMU校正成功、距離換算検証成功を確認。入力のSHA256はhealth.csvに記録。元CSVは変更しない。
- 左右積算パルスの差分、実測換算58.019 pulse/mm、1 msで積算されたimuAngle_Zの差分を使用。疎なgyroVal_Zの再積分は使用しない。
- 周回比較はラインセンサーによる6回のCROSS検出とCADセンサー位置から車軸中央通過位置を推定し、5つの周回間隔を評価。GPIO確定遅延に依存しない。
- 比較する位置はエンコーダとIMUによる推定値であり、外部計測した実位置ではない。

## 車輪ベクトルと識別できる量

以下では前進をf、横をlとし、各区間の距離をmm、旋回角度をradで表す。画像の橙色の矢印は車輪方向の観測値で、斜めの赤い速度ベクトルの大きさではない。縦滑りがなければエンコーダは車輪方向成分を測っている。縦滑りがあればその成分にも誤差があり、今回の幾何分解では取り除けない。

前後車軸間隔は既存のCAD解析結果25.690465 mm、半分a=12.845233 mmを使用。**機体中央の横移動を0と仮定**したとき、前後の接地点の横方向変位は符号規約に応じてそれぞれ±a Δθとなる。左・右の前進変位をdL、dRとすると、車輪の移動ベクトルの大きさDと角度βは次で再構成できる。

```
dL = ΔencTotalL / 58.019
dR = ΔencTotalR / 58.019
l_front/rear = ±12.845233 × Δθ
D = hypot(dWheel, l)
β = atan2(l, dWheel)
forward = D cos(β) = dWheel
dCenterForward = (dL + dR) / 2
```

逆転する車輪の符号も維持する。前進成分の再構成は元のエンコーダ平均と区間ごとに1e-12 mm以内で一致した。この横成分は仮定の下での旋回接地点運動であり、測定された機体中央の横滑りではない。

中央の横移動がl0なら接地点横変位はl0±aΔθとなる。**左右エンコーダと旋回角度だけではl0や旋回中心の前後位置を一意に求められない。** 世界座標のimuAngle_Zそのものを車輪の滑り角βとして使うこともできない。

参考：[Zuoほか、Visual-based Kinematics and Pose Estimation for Skid-Steering Robots](https://arxiv.org/html/2006.04335v6)。この研究は旋回中心と左右の補正係数を扱い、カメラによる並進観測も含めて推定する。IMUと左右速度で求める有効トレッドの初期値だけで前後旋回中心・左右速度誤差が確定するわけではない。

## 追加cos投影の感度実験

ユーザー提案が「エンコーダ値を斜め速度の大きさとして扱い、cosで短くする」ことを含む可能性を検証するため、次も試した。ただしこれは既に車輪方向成分であるエンコーダの**二重投影**であり、横滑り補正として物理的に同定された式ではない。

```
dExtraWheel = dWheel × abs(dWheel) / hypot(dWheel, a Δθ)
dExtraCenter = (dExtraL + dExtraR) / 2
```

0/0は距離0として扱う。静止、直進、逆転、左右等量逆転で符号と有限値を確認。係数の閉路最適化は行っていない。

|対象|Xずれ/周：元→追加cos [mm]|平均閉路誤差/周：元→追加cos [mm]|距離短縮/周 [mm]|
|---|---:|---:|---:|
|12866～12868 CW|16.62 → 16.50|18.47 → 17.41|7.99|
|12869～12871 CCW|14.33 → 13.88|14.47 → 14.14|7.59|
|12885～12888・12890 CW|7.79 → 7.70|8.55 → 8.28|8.05|
|12888のみ CW|6.32 → 6.17|6.56 → 7.52|8.06|

閉路誤差は同一CROSS間のXY変位の大きさを周回ごとに求め、その平均を記載。平均X/Yから計算した大きさとは異なる。12888の平均Yずれは0.02 → +4.18 mm/周となり、Xずれの小さな減少を上回って悪化した。全コースのプロット差は最大25.24 mm。

## 判断と残る調査

前進成分だけを求める幾何分解では、現在の符号付き左右平均から距離は変わらない。追加cos投影は周回Xずれの主要因を解消せず、12888では悪化したため採用しない。実走行の機体中央横移動や縦滑りを確定するには、車輪の回転に加えて車輪中心・機体中心の床に対する移動を観測する必要がある。荷重で旋回中心が前後に移動する可能性は今回のデータだけでは測定できていない。

ファームウェア・ログビューワーの計算は変更していない。解析コードは`analysis/script/check_wheel_projection.py`、表は`per_log.csv`・`lap_intervals.csv`、12888の区間成分は`12888_components.csv`、図は`course_comparison.png`・`drift_comparison.png`に保存した。
