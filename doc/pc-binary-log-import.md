# bin保存とPC側CSV変換

2026-10-15のユーザー指示により、走行終了後・起動時の機体側CSV変換を廃止した。走行終了時のキュー排出、最終書込、閉路検証、CRC・メタデータ保存、truncate/sync/close/renameによる番号付きbin確定は維持する。オートスタートの走行間解析も従来どおりbinから行う。

`control.c`の通常起動・手動終了・5走終了・打切り・緊急停止から旧CSV変換APIを呼ばない。終了時は保存状態を確認して時間・終了結果を表示する。旧APIは既存CSV互換テスト用に残している。

起動時の`logPrepareBinaryStorage()`はbinのヘッダCRC・対応スキーマ・実長を確認し、未確定tmpを検出する。記録全件のCRC検証は解析元を開く時とPC変換時に行う。tmp/partを自動昇格・削除しない。ヘッダまたはI/O不正では開始を禁止し、初期表示に`SD BIN invalid`、tmp検出時は`SD TMP kept`を表示する。機体側の番号一覧はbin/旧CSVをまとめ、同番号を重複させない。PC未取込原本を失わないため古いログの自動削除は廃止した。

## PCの取込

実装先は`C:\tool\AutoCopyCsvFromSd`。既存スクリプト名、`RT_LOG`ラベル、2秒ポーリング、CSV保存先`F:\Dropbox\Document\robotrace\Log\v2`を維持する。

1. SDの番号付きbinを`temp/<入力SHA256>/<番号>.bin`へコピーし、SHA256照合する。
2. 同梱の`RlogToCsv.exe`でヘッダ・全記録・メタデータCRC、対応形式、実長、ファイル名とヘッダ番号を検証する。
3. 同じtemp内へCSVを生成する。保存済みメタデータ・列順・末尾カンマ・CRLF、速度外れ値処理、曲率・クロス補正、保存方位と符号付き距離差によるXYを維持する。
4. 保存先内の作業コピーをSHA256照合し、上書き不可のrenameで正式CSVを公開する。
5. 保存先CSVとSD入力を再照合した後だけSD側原本を削除する。temp内の原本binとCSVは保持する。

同名CSVが同じバイト列なら中断後の再取込を完了できる。違えば上書き・SD原本削除をしない。CRC不正・未知スキーマ・コピー失敗時も原本を保持する。旧CSVは変換せず取込可能。設定、tmp、part、番号以外のCSVは対象外。二重監視をmutexで防止する。

`-SourceFolder <フォルダ> -NoDeleteSource`で原本保持の1回取込ができる。通常監視にPython・MATLAB・コンパイラは不要。変換器のソースと固定ヘッダを同梱し、未知スキーマを推測しない。スキーマ変更時はPC変換器も更新する。

ps1の右クリック「PowerShellで実行」でも起動できる。既存監視が動いていれば二重起動の案内を表示し、Enterまで画面を残す。起動エラーも画面と`temp/startup-error.log`へ記録する。非表示/非対話起動、単発取込、`-NoPause`指定は入力待ちしない。既存監視が起動中なら再実行せずカードを挿せばよい。

## 確認結果

- 通常108/157/183 B・詳細145/194/220 Bの6形式について、実ファームウェアの旧CSV変換をPC上で実行した結果と新変換器のCSVがバイト一致した。90行の非ゼロ診断値、クロス区間、速度外れ値、符号付き保存値を含めた。
- 保全済み実ログ13085（43列・4740行）も同じbinからのPC実行結果がバイト一致した。MinGWのfprintfとsnprintfの丸め差を避け、浮動小数点セルは機体と同じsnprintfで整形する。丁度半分となる値も6形式の回帰入力へ追加した。
- ヘッダ/記録/メタデータCRC破損、未知スキーマ、短い入力を拒否し、正式CSVを作らないことを確認した。
- Windows PowerShell 5.1でコピー・変換・保存後削除、原本保持オプション、同名不一致、同名一致の再試行、CRC失敗、旧CSV取込を隔離フォルダで確認した。設定・tmpを保持した。
- 新しい通常/詳細ホストテストでbin保存後・起動確認後の原本不変、CSV未生成、番号一覧の重複排除、ヘッダ/I/O失敗時の開始禁止を確認した。既存保存・全6形式互換・自動走行/CSV/PATH回帰も成功した。
- Debug/Release×通常/詳細、DebugMarkerのビルド成功。制御周期・PID・SPIクロック・安全判定・保存スキーマは変更していない。新規warningなし。
- 通常Debug版を書込み・全照合・起動済み。ELF SHA256は`8aaab49df42d4d39a97e3bc5e8ca29d741e5033f6c785b1dd19e360901dcc595`。リセットなしの起動後確認でinitMSD=1、initIMU=1、logRecoveryReady=1、modeLOG=0、logTempOpen=0、FatFsロック=0、start/autoStart=0、PWM=0/0、CFSR/HFSR=0を確認した。旧CSV変換関数は最終ELFへリンクされていない。ログI/O共有RAMは0x1800 B、スタック予約0x2000 Bを維持した。

PCとARMでは数学ライブラリや浮動小数点計算の違いがあるため、派生値の最下位桁までのクロスCPUバイト一致は保証しない。
