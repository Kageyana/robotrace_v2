# PATH/SHORTCUTの1ms経路更新

2026-10-25のユーザー指定で、最近傍経路探索・白線観測による自己位置補正・偏差計算・速度/角速度目標更新を5msから1msへ変更した。`routeControllerVersion=18`で識別する。エンコーダ/ジャイロによる自己位置積分は従来から1msであり、その式は維持する。

## 呼出順と時間の維持

`Interrupt1ms()`のPATH/SHORTCUT走行分岐で、`pathFollowerUpdatePose1ms()`→`pathFollowerUpdateTarget1ms()`→ライン/速度/角速度PIDの順に実行する。従来の`cnt5`分岐から経路更新を削除し、同じ周期で重複実行しない。他の5ms周期処理は変更しない。

|処理|1ms化後|従来|
|---|---|---|
|経路逸脱から退避・停止判定|100回、100ms|20回、100ms|
|ライン退避中の白線消失判定|100回、100ms|20回、100ms|
|再合流の条件成立判定|200回、200ms|40回、200ms|
|経路操舵への混合率切替|毎回10/1000、100ms|毎回50/1000、100ms|

横/方位ゲイン、曲率FF、角速度上限±1800deg/s、速度上限、経路生成とSDファイル形式は維持する。

## SD補正係数と1回の補正上限

既存の`lineAlpha_x1000`と`lineThetaGain_x1e9`は5ms基準の保存値として扱い、1ms更新では倍率を戻した値の1/5を適用する。既存の有効なSD設定を自動で書き換えない。1回の補正許可上限も位置1mm→0.2mm、方位0.1deg→0.02degへ換算し、同じ残差での許可条件を維持する。

これは補正量の時間換算であり、5回の小さな更新が従来の1回と完全一致する保証ではない。更新ごとに残差・推定姿勢・白線の対応点を再評価するため、実走行の応答は別途確認する。

## ログと割り込み

ログは通常56列/154 B・詳細62列/163 B、列名・型・順序・自己記述スキーマを維持する。経路診断6列は1ms更新の最新値を既存の距離間隔で保存する。ログ間隔自体を1msへ変更しない。

経路更新はTIM6内で毎回実行するため、その部分の実行頻度が5倍になる。最近傍探索は最大27点、白線照合は最大6区間、白線重心は10センサーの有界処理。SD I/O・表示更新・待機・動的確保は追加しない。割り込み優先度はTIM6=0、TIM3=1、ADC関連DMA=2の既存設定を維持する。TIM6による取得側の待ち時間は増える可能性がある。

ホスト回帰で状態遷移時間・補正換算・保存/CRC/PC変換と、既存のラインADC割り込み競合テストを確認する。Debug/Release×通常/詳細のビルドを確認する。実機の最長割り込み時間、ADC更新欠落、走行安定性は未測定。`ROBOTRACE_ISR_TIMING`の走行中統計と変更後ログで確認し、同条件10走以上で再現性を評価する。
