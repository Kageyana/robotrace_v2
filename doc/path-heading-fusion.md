# PATH_CURVEの白線による位置・方位融合版3

13881では取得版2で全25589周期の白線更新間隔が1msとなった一方、動画では5通過のY変位が+16.57mmで、途中に板外への張出しがあった。従来の融合版2は共分散に方位を含むが、白線更新で方位gainを0にしていた。融合版3は有効白線の残差から横位置・方位・gyro biasを同時に更新する。

`pathFusionFilterCorrect()`へ方位補正[rad]の出力を追加し、実際の自己位置へ毎1ms反映する。Filterは従来の68Bを維持する。白線位置のgainは法線方向へ射影し、マーカーは接線方向の位置だけを更新する。生のIMU角度・校正とCSVの元のXYの意味は維持する。

位置0.2mm/1ms、方位0.02deg/1ms、gyro bias±5deg/sの上限を適用した実gainでJoseph形共分散を更新する。SDの追加方位勾配も同じgainへ合成し、残差15mmのクリップと5ms基準の1/5倍率を保持する。無効入力は補正しない。

現在のSD値`lineAlpha_x1000=5`・`lineThetaGain_x1e9=0`を維持する。後者の0は追加勾配を無効にし、融合版3の方位観測は有効となる。alpha=0・追加勾配0は全補正OFF、alpha=0・追加勾配ありは従来の勾配だけの方位補正とし、共分散・biasを変更しない。通常PATH/SHORTCUTの補正式は維持する。

メタデータは`pathFusionEstimator=3`、`pathWhiteMapVersion=2`。白線地図版2のゴール延長観測、取得版2・TIM6優先度3、信頼度低下時の減速・停止、完全逸脱停止、速度0後の2秒出力保持を含む。通常56列/154B・詳細62列/163Bのログ列とSD形式は維持する。

## 実機確認

書込み前の再確認で、実機Flashが最後の取得計測版886669cc…とは異なったためガードで中断した。RAM・Flashをリセットなしで保全後、保存済み白線地図版2ソースを固定ビルド日時2026-10-28 22:53:41でオフライン再ビルドした。生成された251152Bが実機のプログラム領域と全バイト一致し、続く260Bは消去値だった。実機像を特定してから、そのELFで停止状態を再確認する。その後、ユーザーから13881後に手動書込み／デバッグをしたとの回答があり、操作後の像だったことを確認した。

書込みと起動結果の正は`build/heading-fusion-validation/validation.json`とその起動capture。修正後の実走計測、独立動画との位置照合、同条件での安定した10走、2秒間の実モーター指令は未確認。13854の保存失敗原因も継続調査対象である。

再現入口は`validation/path_heading_fusion/run.py`、`build/heading-fusion-validation/host.py`・`replay.py`・`finalize.py`。保存済み検証の成果物へ別ソースの試験結果を上書きしない。

## 書込みと停止起動の確認結果

ST-Link/SWD再接続後、Device ID0x421・Cortex-M4を確認して計測ON版e98397b5…の書込み・照合・リセット・起動が成功した。再読出ししたプログラム領域253404Bが期待バイナリと全バイト一致した。最初の起動確認はバッテリーAD181・電圧無効で、ユーザーのUSB表示とも一致した。バッテリー接続後の再確認ではAD1963・7.703778V・電圧有効となった。原因をADC換算式の不良と扱わず、製品コードやSD設定は変更していない。

通常setupでpattern/start/auto/log/PWM/計測負荷/IPSRは全て0、IMU/SD初期化は1、CCR2/3・PRIMASK・CFSR・HFSRは0。優先度はTIM6=3・TIM3=1・ADC両系統=2を確認した。SDは位置係数5・追加方位勾配0、直線3.4m/s・加減速20m/s²を保持している。GDB detachと所有サーバー終了を確認した。証跡はbuild/heading-fusion-validation/boot-20261028T151623Z。旧USB給電時の起動ログも元captureへ保全した。

実機用への実装と停止起動確認は完了。操舵が変わった後の実走は未実施なので、新一次とPATH_CURVEの動画付き走行で、横変位・コースアウト・停止理由・実IRQ時間/取得周期を確認する。走行後RAMは電源保持・リセットなしで回収する。
