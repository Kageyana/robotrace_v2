# PATH_CURVEのゴール延長白線地図

一次の終端から原点方向へ走行経路を延長した際、白線地図の延長点が無効のままだった。低速になった13877/13878では、明部が見える状態でも末尾の未照合150msで停止し、高速の13880/13881も末尾61/62msは未照合だった。

白線地図版2では、元の一次の車軸弧長と白線観測を正規化する前に、ゴール延長点に対応する周回位相の観測を準備する。検証済みの周期と閉じずれ補正を使い、補間両端が有効な観測の場合だけ生成する。欠測は無効のまま保持し、車軸経路の延長座標を観測へ代用しない。生成は停止中・FatFsロック下、経路未公開の間だけ行い、延長観測は経路キャッシュと共に保持する。

|原本走行|修正前の再生末尾未照合|修正後|有効な延長観測|
|---|---:|---:|---:|
|13877|149ms|0ms|11/11点|
|13878|147ms|0ms|11/11点|
|13880|60ms|0ms|11/11点|
|13881|62ms|0ms|11/11点|

O0/O2を揃えた保存済み旧ソースとの8再生で、元の白線地図・全走行形状は一致し、修正差は終端の探索窓以降だけだった。通常生成・キャッシュ再利用・設定変更による再生成・PATHとの切替で白線地図の一致を確認した。RAM上の一次コピーを白線全欠測へ変更した陰性試験では、延長も全て無効となり、原本復元後に元の観測地図へ戻る。

単独APIはO0/O2/Wall/Wextra/Werrorで元配列不変・欠測保持・不正入力・補正上限を確認した。Debug/Release/DebugMarker/計測ONの4構成、通常/詳細ログの全CRC・PC再変換・経路/SLIP回帰も成功。新規warning0、RAMは通常79528B・計測80408Bで増加なし。列数とrecordBytesは56/154B・62/163Bを維持し、メタデータのpathWhiteMapVersionを2へ変更した。

候補ELFはbuild/white-extension-validation/WhiteExtensionTiming-2032896d72a23e40cd5584ba589a07da538627e8f7516d48027829a650dc30c4.elf。今回、機体への書込みは行っていない。最後に実機照合した像は取得版2の886669cc…である。

この修正はゴール手前の不要な照合喪失への対処であり、13881の約5.514秒での板外張出し・5通過でY+16.57mmのずれを直したものではない。途中の位置/方位補正の物理整合と、修正後の実走検証・再現性確認が残る。停止条件やSDの補正係数は変更していない。
