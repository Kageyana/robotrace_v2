# 周回ずれを横位置と方位へ分けるための次回撮影

## 目的と現在の限界

版21の13913～13922は10走正常終了したが、同じ直線位置の動画投影に周回とともに数mm増える例がある。白線センサーは車体前方約95mmにあり、その横位置には車体の横位置・方位・横滑りが混じる。現在の輪郭映像と白線重心を、独立な車軸位置/機体方位の真値へ置き換えない。3軸姿勢120組と初期共分散9組の検査でも、物理改善を示す採用候補は得られなかった。

次は機体上の前後2点から**機体の向き**を観測し、動画の移動方向、積算gyro、内部方位偏差、白線重心を比較する。移動方向を機体方位としてフィットしない。動画に合うようgyroの倍率や360°閉路を強制しない。

## 撮影の準備

- 機体上面の同じ平面に、前後で色の異なる丸い目印を2つ付ける。例は前が赤、後ろが黄。固定された位置とし、前後の対応を記録する。
- 取り付け可能な範囲で、2点間を40～50mm以上、各点の直径を8～10mm程度にする。実際の間隔を記録する。これは現在の画角で点を分離しやすくする目安で、精度保証値ではない。
- 2点を結ぶ向きと機体の前後方向が異なる場合は、静止状態で前後方向との関係を記録する。機体上の異なる高さの部品へ1点ずつ置かない。床用マーカーは現在の配置を保持する。
- レンズ高さ・解像度・fpsを記録する。現在と同じ700mmの撮影なら、その条件を使う。開始前と停止後の静止姿勢も録画範囲へ含める。
- 現段階ではファームウェアと速度/制御設定を変更しない。新しい候補が未採用のため、同版で追加9走/10走を一律には要求しない。まず1本の動画とログで2点が識別できるか確認する。

## 解析と受入条件

元解像度で前後点を別々に検出し、床の校正と時刻同期を確認する。欠測/入替/ぼけは無効として残し、gyroや移動方向で点を補完しない。各点の重心・面積・前後距離・静止時のばらつき・検出閾値への感度を保存する。2点の距離が短い場合や1点が隠れた場合は方位を採用しない。

同じ高さの2点について、理想的なピンホール投影の床逆投影は共通倍率になるため、2点間ベクトルの方向を比較できる。実際には高さ差・車体のピッチ/ロール・レンズ歪み・色にじみ・露光の影響が残る。点間距離、画素位置のばらつき、高さ差の感度を示し、既存映像の可視外形中心を車軸位置へ昇格させない。

同じ直線の各通過について、前後点による機体方位、独立な動画の移動方向、保存gyro角の相対変化、内部方位偏差、全10素子値と白線重心、速度/角速度/操舵成分/スリップを照合する。方位が変わるのか、機体方向と移動方向がずれるのか、白線地図との対応が違うのかを切り分けてから、位置/方位/速度モデルの変更を選ぶ。

走行後RAMも使う場合は、停止して電源を保ち、リセット/書込みせずST-Linkへ接続する。保存に失敗したtmpと、再起動前のRAMが失われた走行は別扱いにする。
