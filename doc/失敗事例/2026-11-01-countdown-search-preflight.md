# 読込と依存検索の分離漏れ

確認事実: 初回説明時にrgのパスへinterrupt*を渡しos error 123。変更時にはSkill・再発防止参照の読込と同じ呼出しで未配置robotrace_v2/testsを検索しos error 2となった。既存のglob禁止・読込分離策を適用できなかった再発である。さらに既存失敗記録への不完全な見出しアンカーのパッチは検証で拒否され、変更されなかった。

原因: 参照内容を読む前に依存操作を組み立てたことと、完全行を確認しないパッチ作成。ファーム不良ではない。

対処: 実在するCore/Srcへのディレクトリ検索と-g '*.c'で調査を完了。validationの実在ファイル一覧を別呼出しで取得し、未配置testsを検証先から除外した。失敗パッチを再試行せず専用の本記録を作成した。record-failures SkillはローカルSkill一覧と.codex配下の検索で見つからず、既存記録の形式を使った。

再発防止: Skill・再発防止参照の専用読込呼出しが完了するまで依存検索を組み立てない。任意検索先はTest-PathのTrueだけから配列化し、rg終了2以上で停止する。パッチは読込済み完全行を使い、拒否後は再読込する。flash-debug Skillの実行前にもこの実行点を追記する。

確認方法・結果: 修正したCore検索・validation列挙が成功。要求された3秒カウント・開始2秒後校正を反映し、Debug/Releaseビルドが終了0。1ms内の校正呼出経路と発進条件を維持している。検索・編集手順の対処確認をresolvedとし、実機の表示・発進時刻の検証とは区別する。
