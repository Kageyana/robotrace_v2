# クロス前後の直線化：検索とパッチの入口

- 対象タスク: PATH/SHORTCUT/PATH_CURVEのクロス検出区間と前後100mmを直線扱いする変更。

- 確認: 修正後の検索終了0と対象ソースの一致、拒否後の2新規ファイル不在、その後の適用成功を確認。実Cホスト試験O0/O2とDebug/Releaseビルドが成功した。
