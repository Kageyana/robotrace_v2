# 一次走行でライン由来の反転操舵が約80 mm遅れてコースアウトした

## 要約

一次走行ログ12434～12436は、スタートから約1,000 mmで3走連続して`STOP_LINESENSOR_UNBRIGHT`となった。直前の正常ログ12431と直後の正常ログ12437に比べ、最初の正方向旋回目標が弱く、続く負方向への反転操舵が約73～81 mm遅れた。駆動応答や距離推定の異常ではなく、ラインセンサー偏差から生成される目標角速度が正常走行と異なったことがコースアウトの直接要因である。

## 確認できた事実

- 対象ログ: 12434、12435、12436。
- 比較ログ: 同じ`gitCommit=f34d347`、`optimalTrace=0`の正常走行12431、12437。
- 失敗3本はすべて`emcStop=5`、終了距離994.9～999.1 mm、終了時刻971～972 msだった。
- `emcStop=5`は、中央4個の正規化ラインセンサー値がすべて100未満の状態が150 msを超えて継続した停止要因である。
- 正方向旋回の目標角速度最大値は、正常2本が651、711 deg/s、失敗3本が396～437 deg/sだった。
- 正方向旋回の実角速度最大値は、正常2本が450、464 deg/s、失敗3本が280～292 deg/sだった。
- 負方向目標が-100 deg/sを下回る位置は、正常2本が729.7、730.3 mm、失敗3本が802.9～810.9 mmだった。
- 760～930 mmの負方向目標角速度積分は、正常2本が-101.5、-109.0 deg、失敗3本が-16.3～-19.5 degだった。
- 900 mm付近では正常2本が-779～-847 deg/sを指令していたが、失敗3本は0 deg/sだった。
- 550～930 mmの左右エンコーダ差最大値は、正常2本が72 pulse、失敗3本が50～59 pulseだった。弱い操舵指令に対応して左右差も小さく、左右モーターの一方だけが失速した形跡はない。
- バッテリー電圧は失敗3本が7.91～7.94 V、正常2本が7.82、7.97 Vであり、電圧低下では説明できない。
- 失敗3本は`distanceKalman.invalidUpdateCount=0`、`outputGuardCount=0`、`innovationRejectCount=0`で、`cntlog`最大間隔も11 msだった。距離融合異常やログ欠落ではない。
- スキーマ6の通常ログには`slipFlag`、`lineTraceCtrl`、モーター指令、個別ラインセンサー値が保存されていないため、スリップ、操舵PWM飽和、どのセンサーからラインが外れたかはこのログだけでは確定できない。

## 原因

直接原因は、一次走行のライン偏差から生成される目標角速度が、最初の旋回で不足し、次の反対旋回でも約80 mm遅れたことである。実角速度は弱い目標に応じて同じ傾向で変化しているため、IMUまたは左右駆動系が目標角速度に追従できなかったことが主因ではない。

現行の一次走行`BOOST_NONE`では、目標角速度は概ね`(sensorDiff * encCurrentN) >> 9`で決まり、曲率フィードフォワードは`BOOST_DISTANCE`だけに適用される。このため、スタート位置の横ずれ・向き、ライン観測タイミング、校正値などにより最初のセンサー偏差が小さくなると、操舵開始が遅れやすい。

正常12437も失敗3本と同じファームウェア、PID、速度、`shortcutSettings.lineThetaGain_x1e9=500`で完走している。この設定値やファームウェア差だけを失敗原因とは判断できない。正常と失敗でセンサー偏差が変わった物理的な要因は、通常ログに個別センサー値と開始姿勢がないため未確定である。

## 次の調査と再発防止

- スタート位置の機体横位置とヨー角を治具または基準線で固定し、同条件で最低10本の再現性を確認する。
- 最初の1,100 mmだけ、個別`lSensorCari[0..9]`、合成`senL`/`senR`、`sensorDiff`、`lineTraceOmegaFBCtrl.pwm`、左右速度目標を詳細ログで取得する。常用ログのスキーマは増やさず、一時診断プロファイルを使う。
- 600～900 mmで、ラインがセンサー配列のどちら側から外れるか、目標角速度の反転位置、操舵PWM飽和の有無を照合する。
- 一次走行の最初の小R区間に曲率フィードフォワードまたは速度低減を適用する場合は、原因確定後に別作業として実装し、最低10本で完走率を確認する。
- 解析結果は`analysis/log_12434_12436_start_curve_summary.csv`、`analysis/log_12434_12436_start_curve_aligned.csv`、同名のyaw/XY SVGを参照する。

## 確認方法

同じ開始治具、同じラインセンサー校正、同じバッテリー条件で10本走行し、負方向目標が-100 deg/sを下回る位置が正常基準の約730 mm付近に戻ること、900 mm時点で目標角速度が0にならないこと、`emcStop=0`で完走することを確認する。
