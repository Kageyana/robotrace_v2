# コミット時にGitメタデータの書込み権限が不足

対象: 現在までの変更の段階的コミットとtestsの追跡解除。

確認結果: 通常権限でgit rm --cachedを実行すると、.git/index.lockの作成がPermission deniedで失敗した。最初の操作で停止し、この試行による追跡解除・コミットは行われなかった。

原因: このセッションの権限設定は作業ツリーへ書込可能だが、.gitを読み取り専用としている。

対処: ユーザーの明示的なコミット依頼を根拠に、Git操作をrequire_escalatedで実行。自動承認審査が許可し、追跡解除とコミットが成功した。testsの実ファイルは保持した。

再発防止: Git書込操作前にセッションの.git権限を確認し、読み取り専用なら昇格実行する。index.lockを権限確認なしに削除したり、Git内部ファイルを直接編集したりしない。複数段階のGit操作は各終了コードを確認し、失敗時はそこで停止する。

検証: 6e1c983以降の段階的コミットが作成できた。tests内の既存ファイルがローカルに存在し、git ls-filesでは対象外となることを最終確認する。
