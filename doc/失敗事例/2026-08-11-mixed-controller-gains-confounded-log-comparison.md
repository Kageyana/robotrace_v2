# 制御ゲインが異なるログを電圧差だけで比較しかけた

## 要約
11273〜11371のログを比較した際、ログ群の境界で`lineTraceOmegaFBCtrl`のゲインが変わっていることを後から確認した。制御ゲインの差を分離しないまま、周回タイム差をバッテリー電圧の影響として解釈する危険があった。

## 発生した状況
- 11273〜11290: `lineTraceOmegaFBCtrl.kp=5.00`, `kd=12.00`。
- 11291以降: `lineTraceOmegaFBCtrl.kp=2.00`, `kd=1.00`。
- `gitCommit`は同じでも、ログヘッダの走行パラメータは同じとは限らなかった。

## 何を確認したか
1. ビルド時刻、`optimalTrace`、autoStart、バッテリー電圧を集計した。
2. 後からログヘッダの主要PIDゲインを比較した。
3. 比較結果をゲイン条件ごとに分割した。

## 結果・エラー

```text
同一gitCommitでも、11273〜11290と11291以降でラインヨーFBゲインが異なった。
```

## 原因
比較対象の識別に`gitCommit`とビルド時刻を使い、走行パラメータの全項目を比較条件に含めていなかった。

## 解決・回避策
ゲイン条件ごとに集計し、11273〜11290と11291〜11371を同一条件の性能比較として扱わないことにした。電圧低下の影響は、同一ゲイン群内の時系列比較に限定した。

## 今後の予防策
- 比較前に主要PID、速度FF、速度表、加減速、走行モードをログヘッダから抽出する。
- 条件差がある場合は、電圧差、ゲイン差、速度表差を別要因として表に出す。
- 採用判断では、同一制御条件の最低10本を優先する。
