# 同内容の共有ヘッダにバイト一致を仮定した

通常/詳細の実CとPC変換器のCSV一致、補正距離変更へのXY不変、旧版・必須列欠落の拒否は成功したが、最後の共有ヘッダのread_bytes()一致検査で停止した。

git diff --no-indexではソース差がなく、改行形式の差が残っていた。文書で「同じヘッダ」としていても、配布済みコピーのバイト一致は保証されていなかった。ファームのlogBinary.hを正としてPCツールへCopy-Itemで配布し、両SHA256の一致と検証スクリプト終了コード0を確認した。実装の計算不具合ではない。

再発防止として、共有ヘッダを更新する際は正のファームヘッダから配布し、ビルド前に配布物のSHA256を照合する。意味の同一性と配布物のバイト同一性を別契約として扱う。書込み・ビルドSkillの成果物事前確認へ追加した。

確認: analysis/xy_raw_distance/validation.json。両ヘッダSHA256=6ded40c90164977d90d7bf66107b0671d9ea9833488841fc23e02461c1c073dc。通常・詳細の機体C/PC CSVバイト一致を含む全検証が成功した。計算版2の初回実機ログは未確認。
