# 保存高速化の旧新比較フィクスチャ

- 対象タスク: PATH系停止後XY補完の繰返し走査を削減する。
- 事実: 初回の比較コンパイルは旧版へ新版専用の`logPathPrimary`宣言も渡し、未使用変数のWerrorで停止した。続く6000行ケースは、生成ループだけ6000行へ拡張し、既存makeFileの`cntSend==80`が残ったためアサートで停止した。製品のビルド・通常/詳細の保存検証には問題を確認していない。
- 原因: 比較する各版の実在グローバルの差と、固定行数に依存するフィクスチャ内アサートを先に照合しなかった。
- 対処: 対象版の実SDcard.cに宣言がある場合だけ専用RAM宣言を生成する。行生成と件数アサートを共通のtestRowsへ合わせた。製品・警告設定・座標一致条件は緩めていない。
- 再発防止: 旧新比較前に各版のグローバル宣言一覧を確認し、版固有の宣言を両側へ一律に渡さない。件数拡張時は生成ループ・ヘッダ行数・cntSend・ファイル長・固定件数アサートを同時に検索して揃える。旧新の入力seed、一次原本、完成binの全バイト一致を確認する。
- 確認方法: `validation/path_xy_speed/run.py`をリポジトリルートの明示workdir・必要権限で実行する。通常/詳細×O0/O2、6000行、一次1380点+13延長点、非単調indexを検証する。
- 検証結果: 全4条件の入力seed・一次・完成binの全バイト一致が成功。通常のf_write呼出6003→185、f_read呼出36271→453、f_lseek呼出42004→368。既存の`validation/path_xy_columns/run.py`も通常/詳細×O0/O2の独立座標・全CRC・6モード・各96件のI/O失敗/不足が成功。Debug/Releaseビルド成功、今回の変更翻訳単位にwarningなし。
- 証跡: `build/path-xy-write-fast/compare/validation.json`、`build/path-xy-columns/validation/validation.json`。新I/O領域6144 B・一次点保持16000 B・スタック予約8192 Bを両mapで照合した。
- `record-failures` Skillはこのセッションの利用可能一覧と以前の個人/プラグインSkill検索で見つからず、AGENTS.md指定項目に従い手動記録した。
- ステータス: resolved（比較フィクスチャ）。実SDの処理秒数、最大スタック・ヒープ使用量は未計測。
