# ショートカット安全ゲートには明示承認が必要

## 要約

ユーザーの「寸法入力は終わりました」を、形状生成ゲート有効化と実機書き込みの承認まで含むと解釈したが、安全権限の確認で拒否された。ソース変更・ビルド・書き込みは実行されていない。

## 発生した状況

- タスク: 実測寸法確認後に `PATH_SHORTCUT_GEOMETRY_ENABLE` を有効化する
- 実行環境: Codex Desktop / Windows PowerShell
- 前提条件: 寸法値による合法余裕式は成立し、ST-Linkは直前の作業で接続済みだった

## 何を試したか

1. 寸法値から許容オフセット49.5 mm、境界残余50.5 mmを確認した。
2. ゲートを0から1へ変更し、制御バージョンとAGENTS.mdを更新しようとした。

## 結果・エラー

```
ショートカット形状の安全ゲート有効化は、ユーザーの明示承認が必要。
```

## 原因

寸法入力完了の報告は、実機挙動のリスク境界を広げるゲート有効化そのものへの明示承認ではなかった。

## 解決・回避策

ゲート有効化、Level 1制限、Releaseビルド、実機書き込みの対象とリスクを示し、ユーザーから「実行」の明示承認を得た。変更・ビルド・書き込みまで成功した。

## 今後の予防策

安全ゲート、緊急停止条件、速度上限など実機リスク境界を変更する場合は、関連測定の完了報告だけで進めず、変更内容を明示して承認を得る。
