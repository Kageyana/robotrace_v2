# Codex 失敗事例

Codexが作業中に得た、次回以降のタスクで役立つ失敗と対策を保管する場所です。

- 新規ノートは [_template](./_template.md) から作成します。
- `status: open` は未解決、`resolved` は解決済みです。
- タグは失敗領域ごとに追加します（例: `build`, `test`, `permissions`, `integration`）。

## 失敗の記録基準

「次回の同種タスクで避けられるか」を基準にします。単発の軽微なミスは残さず、原因・対策・予防策まで残せる出来事を記録します。
