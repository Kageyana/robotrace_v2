# Pythonテストの標準一時フォルダ書き込み拒否

- 対象タスク: IMU温度係数CSV互換テスト
- ステータス: resolved

## 確認できた結果

- `tempfile.TemporaryDirectory()`の既定先であるユーザー一時フォルダ配下へ、サンドボックス実行中のPythonからファイルを作成できず`PermissionError`になった。
- 親ディレクトリを作業ツリー配下へ変更しても、サンドボックス内のPythonプロセスでは同じ`PermissionError`になった。
- サンドボックス外ではテスト本体が成功したが、Dropbox同期が一時ディレクトリを保持して削除時に`WinError 32`になる場合があった。
- テスト対象ロジックへ到達する前の実行環境エラーであり、CSV解析処理の不具合ではない。

## 対処

- CSV入力を`StringIO`と`mock.patch`で供給するファイルシステム非依存テストへ変更した。
- 一時ファイルと一時ディレクトリを使用しない状態で3件すべて成功した。

## 再発防止と確認方法

- 読み込み処理だけを検証する単体テストでは、一時ファイルを作らず`StringIO`などのメモリ入力を優先する。
- 実ファイルの作成自体が試験対象の場合だけ、Dropbox外の書き込み許可済み一時領域を使用する。
- `python analysis/script/test_fit_imu_temp_compensation.py`が一時ファイルを作らず終了コード0になることを確認する。
