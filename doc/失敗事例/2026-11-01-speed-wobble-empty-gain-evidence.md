# 14029解析：1ms連続証拠がない一次への空配列集計

- 対象タスク: 14029の高速追従振動と14027の比較。
- ステータス: resolved（解析入力の空証拠処理）。制御原因の単独分離は未解決。
- 確認した結果: 共通読込ループで低速一次14026/14028にも左右速度ゲイン推定を行った。1ms連続3点の条件を満たす証拠がなく、空配列へmedian/meanを呼び、RuntimeWarningとNaNを生成。allow_nan=Falseのsummary.json保存で停止した。生成済みCSVと原本は保持された。
- 原因: 推定用の証拠件数を集計前に検査していなかった。列や全走の行数が十分でも、特定時間間隔の推定窓は0件になりうる。
- 対処: wheel_gainsはsamples=0を保存し、未観測の中央値・一致率のキーを作らない。標準JSONに非有限値を出さず、未観測を正常0へ置き換えない。
- 再発防止: ゲイン推定、スペクトル等の各証拠マスクについて、統計関数の前に件数を検査する。低速一次と高速二次を同じ入口へ渡し、警告をエラー化して空・有効の両方を検証する。ログ解析Skillの実行前参照にも明記する。
- 確認方法: Python -W errorでdiagnose_speed_wobble_14029.pyとprobe_speed_wobble_14029.pyを実行し終了0。一次の推定samples=0と二次の542/786点、summary/probeの有限JSON保存、4原本SHA一致を確認した。図の736/360px表示・系列切替・値表示も成功。
- record-failures Skillは前回のカタログ・個人skills・プラグインcache検索で見つからず、AGENTS.md指定先へ手動記録した。
