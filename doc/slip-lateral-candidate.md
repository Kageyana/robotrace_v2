# 横スリップ残差の接線補正候補

2026-10-12、`codex/slip-detector-v2`に診断専用の横残差候補を追加した。既存IMU出力、従来検出器、初回SHADOWの縦・横・旋回判定と制御への接続は維持する。候補の改善は実機未確認。DWT計測・書き込み・実走行は実施していない。

## 根拠と座標の制約

13094～13124の利用可能な30本では、新横残差と角加速度が強く連動した。13115/13118の相関は−0.982/−0.968、回帰係数は−0.07489/−0.07400 m。これを物理スリップ率や補正係数の真値とは扱わない。解析元は`analysis/slip_shadow_13094_13124/report.md`。

旧参照`Machine/robotrace_v2 v86.step`は現在のチェックアウトに存在しない。存在する`Machine/robotrace_v3.STEP`とメイン基板KiCadのU8（ライブラリ`robocon:BMI088`、Valueは`~`）を確認した。CAD上でIMUは車軸中心から後方31.675 mm、右0.099 mm。コードのY=−0.03168 mと整合するが、CADと実機の一致および生Xの実機正方向は未確認。コードX=0、Y=−0.03168 mは変更しない。出典SHA256と抽出値は`analysis/slip-lateral-candidate/geometry-check.json`。

右X・前Y・上Zを仮定し、CW正の角速度をω、角加速度をα、位置を(rX,rY)とすると、センサー位置の横加速度は次式になる。

```text
aSensorX = aCenterX + α*rY − ω²*rX
必要な中心補正 = −α*rY + ω²*rX
現行コード補正 = +αFiltered*rY + ω²*rX
候補横加速度 = currentLinearX − 2*appliedTangentX
appliedTangentX = αFiltered*rY
```

候補は現行で実際に加算した接線項だけを反転する。共通IMU処理を変更せず、向心項を維持する。LPF係数0.8の角加速度を使用するため、実際の剛体加速度に対して`rY*(α−αFiltered)`の遅れ成分は残る。符号の置換だけで過渡残差がすべて消えるとは扱わない。

## 実装と責務

`IMU_GetTangentialSample()`は同じ`calcVelocity()`で使ったフィルタ後角加速度と適用済みX接線項を返す。`clearIMUval()`と校正開始時に無効化する。IMU演算自体の変更はない。

`Interrupt1ms()`で既存の静止重力除去後の横加速度と上記値を新検出器へ渡す。HAL非依存の`SlipDetection_LateralCandidateMps2()`で候補入力を作り、既存と同じ5 ms移動平均・30 ms残差窓・速度×角速度の計算順で処理する。独立したON 4.6/OFF 3.8 m/s²、ON 3/OFF 5 msの判定を保持する。静止バイアス・走行中の追加学習・実測回帰係数は導入していない。

共通の無効条件に加え、接線項の未取得を理由256、非有限を理由16として候補だけ無効化する。入力が復帰してから43サンプルを満たすまで候補を判定しない。候補が無効でも初回SHADOWの判定は維持する。低電流による抑制はない。

状態と区間統計は1 ms処理側が更新する。ログバッファ保存成功時だけ、同じ処理側で新旧の区間統計を消費する。SD実書き込みは既存のメイン処理で行う。動的確保はなく、検出器状態は1460→1640 B。

## ログ仕様

初回SHADOWの末尾へ次の10列、26 Bを追加する。通常72列/183 B、詳細87列/220 B。CSV末尾空列は数えない。

|列名|保存型|意味・単位|
|---|---|---|
|slipV2LatCandidate|F32|符号付き候補残差 [m/s²]|
|slipV2LatCandidateFlag|U8|候補の判定ON=1|
|slipV2LatCandidateValid|U8|候補の有効性|
|slipV2LatCandidateReason|U16|現在の無効理由ビット和|
|slipV2LatCandidatePeak|F32|記録区間の最大絶対候補残差 [m/s²]|
|slipV2LatCandidateOnMs|U16|記録区間の候補ON時間 [ms]|
|slipV2LatCandidateValidMs|U16|記録区間の候補有効時間 [ms]|
|slipV2LatCandidateIntervalReason|U16|記録区間の候補無効理由OR|
|imuYawAlphaFiltered|F32|現行補正に使用した角加速度 [rad/s²]、瞬時値|
|imuLatTangentialApplied|F32|現行で加算したX接線項 [m/s²]、瞬時値|

候補の理由ビットは既存と共通（1,2,4,8,16,32,64,128）に256=接線項未取得を加える。256は候補だけに使用する。無効時の0を正常扱いしない。区間カウンタは65535で飽和し、飽和区間は率の集計から除く。候補ON率の分母は候補ValidMs、初回SHADOWは既存ValidMsで分ける。候補だけ無効な区間を同条件比較に混ぜない。瞬時αと瞬時接線項を、30 ms窓の残差へそのまま回帰させない。

メタデータには`slipLatCandidateVersion=1`、候補式、未確認を明示した軸仮定、X/Yオフセット、LPF係数、角加速度と接線項の単位を保存する。候補追加時は既存`slipDetectorVersion=2`を維持し、スキーマCRCと候補版で拡張を識別した。2026-10-14の[縦Fast単独比較](slip-long-fast-only.md)から検出器版は3となるが、本候補の式・判定・版1と保存スキーマは維持する。

現行と同じビルドプロファイルに加え、旧通常108 B/詳細145 Bと初回SHADOW通常157 B/詳細194 Bを、プロファイル・固定スキーマCRC・サイズの組で識別して読む。旧4形式は現在のビルドプロファイルに依存しない。初回SHADOW定義は独立した`log_schema_shadow_v2.h`へ固定した。通常の現行183 Bより大きい旧詳細194 Bも読める受信バッファを確保した。変換CSVは元の列を保持し、未記録の候補列を正常値として補わない。不明形式・CRC異常・サイズ不正は拒否し、CSV確定前は原本を削除しない。
