## 2026-10-18：角加速度LPFとの時間応答をそろえる候補版5（導入時の履歴）

ユーザーの修正指示により、横候補内部で接線補正を除いた残差へ一次LPFを追加する。候補版5、ON5.2/OFF4.5m/s²、ON3ms/OFF5ms。共通IMU・角加速度LPF・縦判定・初回SHADOW横・従来制御・距離補正・次走計画は変更しない。通常72列/183B・詳細87列/220Bを維持する。

同じ5ms平滑化・30ms窓を通した共通横残差をR0、従来の`currentX−2*T`から求めた未整合残差をUとする。速度と角速度はそれぞれ5ms移動平均した後に掛ける。

```text
Rn = 0.5*R0 + 0.5*U       # 接線補正を除いた残差
Tbar = 0.5*R0 - 0.5*U     # 同じ窓を通した適用済み接線項
F[k] = 0.8*F[k-1] + (1-0.8)*Rn[k]
slipV2LatCandidate = F[k] - Tbar[k]
```

追加LPFの係数は角加速度LPFと一致することをビルド時に検査する。未来値参照・9ms固定先行は行わない。比較側も遅らせる方式で、確認されたソフトLPF由来の約4msの応答差を対象とする。残るセンサー内部遅延等を含め、全9〜10msの相対遅れを解消したとはしない。

開始時・無効後の復帰は43サンプル充填後の最初の有効RnでFを初期化する。無効時はFと初期化済み状態を消去し、非有限値は候補を無効化する。ログ区間統計のリセットではFと継続状態を保持する。追加の20ms無効期間は設けない。提案時の疎な近似で冒頭20サンプル未満を除いた扱いは解析上の比較条件であり、この実装の有効性規則ではない。

`slipV2LatCandidate/Peak`は上式の整合後残差とその区間最大絶対値に意味が変わる。候補フラグと区間ON時間も整合後残差で求める。`imuYawAlphaFiltered`と`imuLatTangentialApplied`は従来どおり共通IMUの瞬時スナップショット。版5の保存済みR0と候補残差から`(R0±Rc)/2`を計算してRn/Tbarへ戻してはならない。この逆算が成立するのは追加LPF前の版1〜4の残差である。

メタデータは`slipLatCandidateVersion=5`、`slipLatCandidateFormula=lpf_neutral_minus_windowed_tangent_X`、`slipLatCandidateLpf=0.800000`、`slipLatCandidateLpfInit=first_valid_neutral_reset_on_invalid`を保存する。既存の`slipLatAlphaLpf`は共通IMU角加速度側の係数を表す。検出器版3/fast_onlyは維持する。

暫定ON5.2は、既存48ログの近似比較でフィルタ整合後の既知動画陽性16窓を保持する値として選定した。ON6.0を固定した案では2窓を取りこぼしたため、後段でON4.6〜6.0を0.1刻みで探索した。3補間方法・±半フレームで全窓のON重なり16ms以上を保持する最大値が5.2、最小重なりは30msだった。全陽性窓を選定に使用し、独立確認済みとしない。一次の不要ONは残り、追加LPFによる短い滑りの減衰・検出遅延は実機確認が必要。提案の比較証跡は`analysis/matched_filter_proposal/`に未実装時点の記録として保持する。

右X・前Y・上Zを仮定し、CW正の角速度をω、角加速度をα、位置を(rX,rY)とすると、センサー位置の横加速度は次式になる。

```text
aSensorX = aCenterX + α*rY − ω²*rX
必要な中心補正 = −α*rY + ω²*rX
現行コード補正 = +αFiltered*rY + ω²*rX
候補横加速度 = currentLinearX − 2*appliedTangentX
appliedTangentX = αFiltered*rY
```

候補は現行で実際に加算した接線項だけを反転する。共通IMU処理を変更せず、向心項を維持する。LPF係数0.8の角加速度を使用するため、実際の剛体加速度に対して`rY*(α−αFiltered)`の遅れ成分は残る。符号の置換だけで過渡残差がすべて消えるとは扱わない。

## 実装と責務

`IMU_GetTangentialSample()`は同じ`calcVelocity()`で使ったフィルタ後角加速度と適用済みX接線項を返す。`clearIMUval()`と校正開始時に無効化する。IMU演算自体の変更はない。

`Interrupt1ms()`で既存の静止重力除去後の横加速度と上記値を新検出器へ渡す。HAL非依存の`SlipDetection_LateralCandidateMps2()`で候補入力を作り、既存と同じ5 ms移動平均・30 ms残差窓・速度×角速度の計算順で処理する。独立したON 4.6/OFF 3.8 m/s²、ON 3/OFF 5 msの判定を保持する。静止バイアス・走行中の追加学習・実測回帰係数は導入していない。

共通の無効条件に加え、接線項の未取得を理由256、非有限を理由16として候補だけ無効化する。入力が復帰してから43サンプルを満たすまで候補を判定しない。候補が無効でも初回SHADOWの判定は維持する。低電流による抑制はない。

状態と区間統計は1 ms処理側が更新する。ログバッファ保存成功時だけ、同じ処理側で新旧の区間統計を消費する。SD実書き込みは既存のメイン処理で行う。動的確保はなく、検出器状態は1460→1640 B。
