2026-10-27。PATH_CURVEの周回ずれを抑えるための検証実装。変更後の実走行の完走性・制動距離・位置精度は未確認。

## 位置観測と走行地図

左右生エンコーダとジャイロによる1 msの位置伝播を維持する。PATH_CURVEでは、一次走行の車軸付近のXY経路と、前方のラインセンサーが実際に観測した白線位置を分ける。一次の10素子値から背景400を除いた重心を計算し、800以上の明部が1群・幅1～4個・重み合計1200以上の場合だけ、一次の保存方位・位置と素子座標で白線観測点を生成する。一次で白線が不明瞭な点を有効な観測で補完しない。

車軸経路点から20 mm以内の最も近い一次観測を保持する。白線対応は車軸の最近傍位相を基準に後方2点・前方4点に限定し、方位差60 deg以内、白線残差30 mm以内を受理する。車軸経路自体を前方白線の地図とみなすと、小Rカーブで正常な白線にも大きな残差が生じることを実制御の再生で確認した。

一次のCROSS間に300～420 degの旋回があり、間隔2～8個、周期1～10 m、中央値からの差5%以内なら周回周期を決める。一次の1周目だけを使い、50 mm以内の並進閉じずれを弧長へ分配した同じ地図を各周へ繰り返す。車軸経路と白線観測地図に同じ変換を適用する。周期が検証できない一次では元の非周期経路・白線観測を使い、マーカー補正を無効にする。周期は開始時に固定し`pathLoopPeriod_mm`へ保存する。変換に失敗した経路は開始しない。

走行中は白線地図への法線残差を、位置・方位・残留ジャイロずれの4状態の共分散で扱う。位置補正gainを観測方向へ投影し、白線の相関だけで進行位相を動かさない。方位は直接更新せず、推定したずれを次のジャイロ伝播から引く（上限±5 deg/s）。白線・マーカーを合わせた位置補正は毎1 msに0.2 mmまでに制限し、gainの制限を共分散にも反映する。白線分散は5ms基準25/(品質×lineAlpha/5) mm²を1msの観測頻度へ換算して5倍とする。移動距離に対応する伝播分散も同じ5ms基準へ合わせる。従来PATH/SHORTCUTの係数の意味を維持し、PATH_CURVEではlineAlpha=5を基準強度1、0を無効として使用する。スリップ残差は相関した独立位置観測として重ねず、最大リスクの品質重みとして用いる。スリップ診断無効時の重みは0.25。方位補正は既存SD係数を使用し毎回±0.02 degまでとする。係数0は無効のままであり、SDの有効値をコードの既定値で上書きしない。

マーカーは種類、経路点差±8点、方位差±20 deg、接線残差150 mm以内が一致する新規イベントだけ採用する。接線方向の位置観測分散100 mm²で融合し、マーカーではジャイロずれを更新しない。1イベントでも0.2 mm/1 msの合計上限を守る。CROSSを無条件に周回や原点とみなさない。

## 白線未観測と自己位置の信頼度

PATH/SHORTCUT/PATH_CURVEは、新鮮な明部の存在と有効な地図照合を独立に監視する。取得電源ON・更新件数非ゼロ・取得後3 ms未満の値だけを新鮮とする。

|状態|減速の条件（どちらか）|自己位置喪失の条件（どちらか）|
|---|---|---|
|新鮮な800以上の明部なし|20 ms / 40 mm|60 ms / 120 mm|
|有効な白線地図照合なし|60 ms / 120 mm|150 ms / 300 mm|

信頼度0～1000は、上記の停止閾値に対する未観測時間・距離の最大割合から求める運用上の指標であり、正解位置に対する確率や誤差上限ではない。古い明部の保持では回復しない。有効な白線照合が100 ms連続してから通常速度へ復帰する。喪失は走行リセットまで保持する。

減速時の速度上限は1.0 m/sとSDのsearchの低い方とし、SDの加減速度（最大20 m/s²）で目標を変える。減速度0の場合も信頼度低下時は20 m/s²で減速する。曲率FFも減速後の目標速度へ合わせる。照合不成立中に単一白線が見える場合は既存ライン追従へ退避する。喪失時は目標速度・角速度0、既存の`STOP_LOCALIZATION`（emcStop=7）を要求する。

全10素子100未満20 msの完全逸脱停止（emcStop=5）は継続する。20/60/150 msは判定時間で、物理的な停止完了時間ではない。
