# ショートカットの50mm上限と大変位区間の除外（制御版28）

一次14038の80mm解析で得たP1・P3を除外し、残るP2・P4・P5・P6・P7と従来C1をSHORTCUTで走行するため、候補抽出と採用判定を分けた。

- 候補抽出上限は80mm。浅い蛇行も含む反転2回以上を抽出する。
- 採用上限は指定50mmと既存の合法余裕49.5mmの小さい方。寸法、15mmの追従誤差予算、10mmの合法余裕、機体外形・板端条件は変更していない。
- 候補の入口・出口の補間を含む全点を検査し、1点でも採用上限を超えた場合はその候補の全区間と前後100mmを除外する。採用限界で変位を切り詰めたり、同じ区間から小さな候補を再抽出したりしない。
- 採用できる候補だけを適用し、整数座標へ丸めた後も変位上限50mm、合法余裕に丸め許容0.5mmを加えた上限、新規交差、全体短縮量を検査する。
- 除外区間は元経路で走る。除外印は短縮区間の保護印と別であり、白線・マーカーによる位置補正や白線退避を抑止しない。

14038の結果は、P2=index147～187、C1=1416～1456、P4=1576～1598、P5=1604～1633、P6=1639～1665、P7=1671～1694の6区間。P1=index30～70とP3=418～443は前後5点も含めて元経路を保持する。ログ番号・経路indexの例外を製品へ固定せず、最大変位を超える候補を全体除外する一般的な規則で実現する。

探索は停止中・FatFsロック下でのみ実行し、公開前に計画を無効化する既存経路を使用する。候補を処理するたびに採用保護印または除外印を付けるため同じ候補を繰り返さず、採用上限16区間まで探索する。動的メモリ・共有RAMの増加は無い。キャッシュ利用時も基準経路から保護印と除外印を消して再生成する。PATH/PATH_CURVEでは両印を使用しない。

既存の速度上限、曲率に応じた速度、加減速、先行減速、1ms自己位置・操舵・停止処理、SD設定の保存形式とログ列は変更しない。生成方針の識別はrouteControllerVersion=28を使用する。

検証入口はvalidation/shortcut_limit/run.pyとbuild.py。実CをO0/O2・Wall/Wextra/Werrorで実行し、50mm境界・49.5mmの合法余裕、除外印が白線補正を止めないこと、一次14038の6区間、P1/P3の完全除外、残る経路全点と80mm解析の選択済み区間との一致、キャッシュとPATH/PATH_CURVE切替を確認する。Debug/Releaseの変更前後でRAM、既存警告、ログスキーマ、割込みと停止・制御経路のソース不変を照合する。結果はbuild/shortcut-limit-20261101へ保存する。

検証結果は全件成功。一次14038の6区間は合計54.2695312mm短縮、最大変位46.6154481mmで、P1/P3を元経路へ戻した80mm解析の全1724点と一致した。O0/O2の全出力が一致し、白線補正・喪失停止・再合流・キャッシュ・モード切替も成功。Debug/Releaseビルド成功、新規warningなし、静的RAMの各セクション・予約スタックは変更前と一致。割込み・制御・停止条件・ログスキーマの不変確認も成功した。ローカル検証コードは既存方針に従いGit管理対象外のvalidation/へ保存する。

実機への書込み・走行確認は今回のコード検証に含めない。最初の実ログで版28、SHORTCUT、参照一次、偏差、追従状態、停止理由を確認する。新たに採用する区間は白線への補正を抑止するため、特にP5の約46.6mm変位でライン観測・制動・追従を確認する。同条件10本以上の実走で完走・再現性・ラップタイムを比較する。
