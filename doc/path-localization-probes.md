# 残る周回ずれの追加モデル検査

版21・一次13911の13913～13922は10走完走し、動画の相対Y変位には数mmの増加が残る。ファームウェアを変更する前に、3軸姿勢と初期共分散の仮説をPC上で検査した。今回は実機接続・書込み・SD設定変更なし。

- 3軸姿勢：13922の保存RAMから静止時重力基準を回収した。保存X/Yジャイロと1ms積算Z角の差分を使う全120組と合成18旋回を確認。保持基準・全3軸で記録Z角との差は最大約0.08°、X/Y再構成法の差は約0.03°。初期基準が失われた一次13911へこの基準を転用しない。現行`imuAngle_X/Y`は`USE_ACCELE`分岐で加速度角をLPFした値で、ジャイロ積算を含む動的姿勢ではない。
- 初期共分散：方位SD1/3/5°、bias SD0.2/0.5/1°/sの全9組を、既知真値486条件と22走×9組×O0/O2の396再生で確認。既定22走は凍結C21へ全バイト一致し、全候補でO0/O2一致、有限値・補正上限・未照合加速保留を維持した。変更したPC用`pathFusion.c`は`-Wall -Wextra -Werror`でも確認した。
- 採否：初期共分散を増やした8組は、調査済み10動画との再生不一致RMSE平均を全て悪化させた（基準1.631mm→1.724～2.212mm）。合成直線での改善を理由に採用しない。3軸姿勢にも今回の物理改善を示す根拠がない。既定値・実機版21を維持する。

保存入力の再生は実機の新しい閉ループ運動を予測していない。動画は可視外形の床投影で、真の車軸位置・方位ではない。13898末尾の未照合145～149msを、実際の150ms停止や板内復帰の証明へ読み替えない。残る白線地図と実運動のモデル差、横位置/方位の配分、13912の早期停止・保存失敗、RAM9区間の帰属は未解決。目標完了とはしていない。
