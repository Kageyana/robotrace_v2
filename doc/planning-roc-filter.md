# 大会図面とのROC比較と速度計画の平滑化（2026-11-03）

このページの計測値は平滑化実装時点の検証結果である。その後、ユーザー指定で`filteredROC_mm`をログ末尾へ追加した。追加列の現行仕様・形式・検証は[フィルタ済みROCログ](filtered-roc-log.md)を参照する。

11/2・11/3の一次ログ10本を、2026中部大会のコース図面と比較した。R200～R500は概ね同程度だった。R2600～R3000には変動があり、短い連続R100は図面より緩い。大半径の変動を減らす処理を追加したが、短いR100の形状差を解消したとは判断しない。

## 入力と比較方法

- PDF原本: `C:/Users/ucawa/Downloads/26_robotracetubu_v2.pdf`、1ページ。SHA256 `917fbb6b74c128664f9d96060c3a912f2a9ee5748d852cc79a1eb8fc708f19aa`。
- 一次: 14051、14052、14055、14063、14067、14070、14072（11/2保存）、14076、14080、14083（11/3保存）。buildDateではなく日本時間の保存日で分類した。
- 34本を棚卸ししてoptimalTrace=0の10本を選択。全行幅、数値の有限性、時刻の単調増加、logExpectedRowsとの一致、原本SHAを検証した。全てemcStop=0、closureValid=1。原本binの全CRCは今回再検証していない。正常ログ終了と物理的な板内完走の確認は別である。
- PDFの黒線49円弧・19直線を接続した。寸法線から0.189 PDF pt/mmとし、円弧のBezier微分から曲率を計算。接続部の作図隙間は最大約1.3mm、黒線長は36,678.5mm。R100/180/200/300/350/500/2600/2800/3000を確認した。赤い注記より黒線形状を優先した。
- 生左右平均距離と保存済み積算方位を使い、図面方位と距離を対応付けた。全体の距離倍率と開始ずれを診断後、円弧ごとの方位で±150mm内の位置ずれを補正した。新旧フィルタの評価位置は共通であり、フィルタ出力から対応位置を選んでいない。
- 境界の25%（20～100mmに制限）を除いた内部を評価。短い直線は主評価から除いた。指標は各円弧内の `median(abs(推定R/図面R - 1))` を取り、10本・同半径円弧で中央値を取ったもの。図面の公称値は実走行中心や実機の車軸軌跡と同一とは限らず、短いS字の対応方位にも残差がある。

ログの最終生距離は35.984～36.034m。図面に対して約2%短く、開始/終了基準、実コースの寸法、走行軌跡、距離換算の寄与は分離していない。この比較だけで検証済みの58019pulse/mを変更しない。

連続する短いR100の中央9円弧では、現行PATH計画の区間中央値は197～276mm、全区間中央値230mmだった。瞬時gyro/速度にも図面の±10[1/m]より小さい振幅が見える。一律150～250mmの平均は旋回方向を打ち消し、さらに半径を大きくするため不採用とした。走行軌跡・観測位置・追従応答と推定の寄与の切り分けが必要であり、公称R100への係数補正や置換は行わない。

DISTANCEは従来から50mm区間の半径中央値とR2800超の直線化（R3000）を使う。大半径だけを保存方位から再評価して平滑化した。R3000へのクリップがあるため、その値の一致を真のR3000の推定精度として扱わない。

## 実装

- `courseAnalysis.h`の`PLAN_ROC_FILTER_MIN_RADIUS_MM=700`を急旋回保護の境界とする。
- DISTANCE/SLIP一次計画: 従来の50mm中央値は保持する。保存積算方位を50mm境界に補間して符号付き曲率を別途求め、前後2区間を含む250mmの全区間がR700以上のときだけ平均する。R700未満を含む窓は元の中央値を使う。SLIP前の`rocAbsSum`作業領域を共用し、SLIP開始時の既存ゼロ初期化を維持する。
- PATH_CURVE/SHORTCUT_CURVEの一次速度半径: 既存の丸め前XYによる80mm局所推定を保持し、20mm間隔11点を対称平均する。合成した窓幅は280mm。窓内にR700未満がある場合、局所推定の端が欠ける場合は元の半径を使う。計画確定前だけ半径欄を符号付き作業領域にし、公開前に全点を正の半径へ戻す。
- 半径そのものではなく旋回方向を保った曲率 `sign/R` を平均し、最後に半径へ戻す。閉路正規化の既存処理も維持する。
- PATH/SHORTCUTの共通速度生成にも同じ一次半径を渡す。経路形状・候補採否・白線地図・操舵FFの計算窓は変更しない。瞬時ROCのログ列、計算版2、スキーマ、列数、緊急停止も変更しない。
- 追加処理は停止中・FatFsロック下の解析だけで動く。動的確保や常設RAM配列は追加しない。
