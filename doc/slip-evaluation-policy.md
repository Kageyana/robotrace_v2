# XY基準・動画によるスリップ評価の優先順

2026-10-18のユーザー指定。今後のスリップ評価と閾値調整で使用する。ファームウェア内の判定とは別の、オフライン検証用の正解ラベル決定手順。

## 1. 最初にXYずれで滑り有無を判定する

対象系列の基準一次走行を特定する。13459～13462の基準はユーザー確認済みの13458。今後の別系列へ13458やその数値を無条件に使い回さない。手動走行で参照番号が未記録なら、対象一次の指定を確認する。

[手動一次参照の保存変更](manual-run-primary-log.md)後は、手動走行でも有効な計画元の番号を`primaryLogNumber`から取得できる。旧ログの0を推測で補完しない。

各走行で次を求める。

- `Dx = abs(X_goal - X_start)`：始点から終点までのX差の絶対値 [mm]
- `Dy = abs(Ymax_last - Ymax_first)`：最終周と1周目の最大Y差の絶対値 [mm]

2026-10-18の追加指定により、Y条件を一次走行に対して**±20mm以内**へ変更した。X条件とDyの絶対値定義は維持する。

`Dx <= Dx_primary AND abs(Dy - Dy_primary) <= 20 mm`ならXY判定は**滑りなし**。どちらかの条件を外れれば**滑りあり（XY条件外という検証ラベル）**とする。Yの許容区間は`max(0, Dy_primary - 20) <= Dy <= Dy_primary + 20`。両端の等号を含む対称な帯域であり、上限だけを20mm増やす条件にはしない。判定前の丸めや指定20mm以外の許容幅は入れない。基準付近の余裕・記録間隔への感度は併記する。

一次13471ではDx上限23.727084mm、Dy基準22.531555mm、Y許容区間2.531555～42.531555mm。直近13472～13479への適用結果は`analysis/video_slip_13472_13479_yband20/report.md`。旧Y条件の結果は元フォルダに保持する。新規解析はXY→動画の順を維持し、既存動画判定を再利用してルールだけ変更した再評価は、その時系列と旧新ラベルを別に記録する。

XYはマーカー補正前の生左右積算平均距離と保存済み`imuAngle_Z`を用いる計算版2で統一する。始点はスタート原点、終点は保存済みゴールマーカー立上りを使用し、停止までの余走を含む記録終端との差は別に示す。一次と対象で定義をそろえる。右マーカー記録行をSG加算と同一視せず、各周の最大Yの所属はCROSS反復・軌跡・積算方位などで照合する。指標や基準が欠ける場合はXY未判定とし、正常ゼロで補完しない。

## 2. その後で動画判定を行う

XY判定を先に保存してから、原動画で滑りあり・なし・不確定を判定する。ログと動画の対応、床校正、マーカー所属、同期、欠測、評価区間の被覆率を確認する。検出器の残差やONで正解を選ばない。映像から求めた横方向移動指標や矢印の差だけで、動画判定を確定しない。

|動画判定|閾値調整に採用する最終ラベル|採用根拠|
|---|---|---|
|滑りありと明確に確認|滑りあり|動画|
|滑りなしと明確に確認|滑りなし|動画|
|不確定|先に保存したXY判定|XY基準|

XYも未判定で動画も不確定なら、最終ラベルは未判定のまま保持する。XYと動画が食い違っても、それぞれの判定・理由を消さず、明確な動画判定を採用したことを記録する。過去の動画ラベルを、指示なく不確定へ変更してXYへ置き換えない。

## 3. 最終ラベルを正として閾値を調整する

動画が不確定な走行はXY判定を閾値調整の正として使用する。XY基準が物理滑りの真値を直接測ったことを意味するとは報告しない。

結果には基準ログ番号、Dx/Dyと許容幅、XY判定、動画判定と確実性・確認区間、最終ラベル、採用根拠、入力ハッシュを残す。走行単位のラベルから全時刻・全ONを正検出と決めず、局所の検出位置・継続時間を評価するときは、動画で確認できた区間を別に保持する。縦横を動画・XYで分離できなければ、縦または横の確定ラベルを捏造しない。

判定ラベルを固定してから、選定用と確認用を走行単位で分け、不要ONと見逃しを比較して閾値を修正する。確認用で選び直さず、変更対象以外の速度計画・窓・継続時間などを固定する。実記録カウンタと疎な残差の補間近似を区別する。閾値を変えても制御への採用は別に確認する。

解析だけの回ではファームウェア・実機設定を変更しない。閾値実装・書込みは、その作業の依頼範囲に従う。

2026-10-18の既存ログによるV2修正では、ユーザー指定によりモータ指令電圧の上限が同じ走行を同条件とし、バッテリ電圧差だけでは比較から除外しない。電圧は参考値として残し、方式・速度表・PID・一次参照等の差は別に記録する。同じ指令上限を、実際の出力電圧や物理挙動の完全一致を測定したことへ読み替えない。
